# UBIK Solutions Homepage: handoff

## What's in this zip
- `index.html`: the full homepage (CSS and JavaScript are inline).
- `assets/`: empty. You need to add the 27 files listed below.

## Files to copy into assets/
These are the paths the page loads. Copy each one from the original artifact so the names match exactly.

## Running it
Open index.html in a browser. The page uses Google Fonts (Manrope) and GSAP/Lenis from CDNs, so it needs an internet connection.
